# Markform Studio

A single-page website for **Markform Studio**, a logo design studio owned by Teagan Wan.

## How to open

Open the homepage in any modern browser:

```bash
# From this folder
open index.html
```

Or double-click `index.html`, or drag it into a browser window.

Path: `/workspace/markform-studio/index.html`

No build step or server required — the page is self-contained (HTML + embedded CSS/JS). An internet connection is needed only for the Google Fonts stylesheet.

## What’s included

- Hero with studio name, tagline, and CTA
- Services (logo design, brand identity, redesigns, usage guidelines)
- Sample logo concepts (original geometric SVG marks)
- Contact form (front-end only; shows a confirmation on submit)
